# OFM-IPCameraModule

OpenKNX module for integrating IP cameras into the KNX bus. Supports bidirectional control and event reporting.

## Supported Manufacturers

- **Reolink** (Phase 1–3, full support)
- Hikvision (planned)
- Dahua (planned)

## Features (Reolink)

- Motion detection, AI detection (person, vehicle, animal, pet, package, face, baby alarm)
- Doorbell trigger + hold, Do-Not-Disturb, auto-reply
- Chime control (mute, volume, ringtone, manual trigger)
- Siren, floodlight, IR LEDs, PTZ preset, privacy mode
- Push notification enable/disable via KNX
- Battery status, sleep state (battery cameras)
- WiFi signal strength (WLAN cameras)
- Recording control, motion detection enable/disable, auto-tracking
- 8 channels per device, NVR channel index support
